A mobile guide to Tallinn sights built with .NET MAUI. Browse places by category, read details, save favourites, and manage places in an admin section.

## Features

- List of Tallinn sights (Toompea Castle, St. Olaf's Church, Kiek in de Kök…) grouped by category
- Place cards with a photo, description and address
- Favourites
- Admin page: add, edit and delete places
- Local SQLite database
- Interface in Estonian, English and Russian
- Tab navigation (Explore / Favourites / Admin / Settings)

## Tech

C#, .NET 10, .NET MAUI, SQLite (`sqlite-net-pcl`), MVVM (ViewModels, Commands, ObservableCollection).

## Run

Open `CityExplorer.slnx` in Visual Studio 2022+ with the .NET MAUI workload and run on Android Emulator or Windows Machine.
